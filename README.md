# Obsidian Clean Empty Lines Plugin

Плагин для [Obsidian](https://obsidian.md), который наводит порядок с пустыми строками в заметках:
- **Удаляет дублирующиеся пустые строки:** схлопывает 2 и более подряд идущих пустых строк в одну.
- **Расставляет пустые строки вокруг заголовков:** гарантирует аккуратные отступы перед и после заголовков (`# Header`).
- **Удаляет пустые строки между элементами списка:** делает списки компактными (поддерживает `-`, `*`, `+`, нумерованные `1.`, задачи `- [ ]` и вложенные списки).
- **Удаляет горизонтальные линии `---`:** удаляет разделители в тексте, при этом сохраняя метаданные YAML frontmatter.
- **Защищает блоки кода и формулы:** содержимое блоков ` ``` ` и математических формул `$$` не затрагивается.

---

## Установка

### Ручная установка в ваше хранилище (Vault)

1. Откройте директорию вашего хранилища Obsidian.
2. Перейдите в папку `.obsidian/plugins/` (если её нет — создайте).
3. Создайте папку `obsidian-clean-empty-lines`.
4. Скопируйте в неё файлы:
   - `manifest.json`
   - `main.js`
5. Откройте Obsidian -> **Настройки** -> **Сторонние плагины** (Community plugins) -> нажмите **Обновить** (кнопка рядом со списком установленных плагинов).
6. Включите плагин **Clean Empty Lines**.

---

## Использование

1. **Команды в палитре (Ctrl/Cmd + P):**
   - `Clean Empty Lines: Очистить пустые строки в активной заметке` — форматирует весь активный документ.
   - `Clean Empty Lines: Очистить пустые строки в выделенном фрагменте` — форматирует только выделенный текст.
2. **Иконка на панели (Ribbon):**
   - Нажмите иконку со списком и галочками на левой боковой панели Obsidian, чтобы быстро отформатировать активную заметку.

## Настройки

В настройках плагина можно гибко включить или отключить:
- Схлопывание дублирующихся пустых строк.
- Пустую строку перед заголовками.
- Пустую строку после заголовков.
- Пустую строку между смежными заголовками (например, `# H1` и `## H2`).
- Удаление пустых строк между элементами списка.
- Очистку пустых строк в начале и в конце файла.
